### Recent project

**What can selectively reported susceptibility labels tell us? Cross-hospital evaluation of antimicrobial-resistance prediction**
<br><sub>NTU course project, 2026 · with Li BingRui</sub>

- Laboratories often report a broad-spectrum antibiotic result only when a narrow-spectrum one is resistant. We asked which conclusions about a resistance model hold on the recorded labels, and which depend on assumptions about the unreported ones.
- Urine *E. coli* cultures from three US hospitals (ARMD); logistic regression, XGBoost and a permutation-invariant Transformer encoder over prior isolates, built in PyTorch.
- Exact ranges over the unreported labels, controlled selection experiments, inverse-probability weighting and a pre-specified replication across organisms and drugs.
- 🎬 Demo video: [youtu.be/bOCnNe4AOEE](https://youtu.be/bOCnNe4AOEE)
